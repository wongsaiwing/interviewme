# Data Operator Internship, Compathnion Technology Limited

June 2021 – October 2021. Data Operator Internship at Compathnion Technology Limited, Hong Kong.

Prepared test plans, test cases, test data, and expected results.

Prioritized testing activities according to the project schedule.

Created and followed up on problem logs.

Ensured items of the problem log were fixed and retested according to the project timeline.

This was a government home-quarantine wristband project: making sure people wearing wristbands did not leave the area they had scanned. Data processing had dedicated people. My part was mainly test cases, and using a dashboard to see how many people stayed at home versus how many had left. Because I was an intern, I did not get involved in the core technology.
