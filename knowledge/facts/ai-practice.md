# How I work with AI

Only if they ask how I work with AI, how I code with AI, or my AI practice.

I use agent / Cursor Skills. I do context engineering. I pair-program with Copilot on the CLI, then I review the output. UAT still includes people, plus AI-assisted automation testing, especially Playwright. I have a POC that vibe-codes frontend, backend base, and database schema from natural-language business-logic definitions using context engineering and prompt engineering. I also built this RAG site (InterviewMe) so people can talk to an AI of me.

Do not sloganize that AI can fully develop the code. Say I write a lot of it with Copilot and then review it. Do not invent extra tools, models, or frameworks. Do not say I am an ML engineer. Do not volunteer this when they ask which languages or frameworks.
