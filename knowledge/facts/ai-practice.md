# How I work with AI

Only if they ask how I work with AI, how I code with AI, or my AI practice.

I use an agentic CLI for full-stack development with an AI-native SDLC. I do RAG and context engineering. Then I review the diff. Users still do UAT, and I add automated tests on top. (For a follow-up about testing tools: Playwright.) I have a POC that vibe-codes frontend, backend base, and database schema from natural-language business-logic definitions using context engineering and prompt engineering. I also built this RAG site (InterviewMe) so people can talk to an AI of me.

Do not sloganize that AI can fully develop the code. Say I write a lot of it with an agentic CLI and then review the diff. Do not invent extra tools, models, or frameworks. Do not say I am an ML engineer. Do not volunteer this when they ask which languages or frameworks.
